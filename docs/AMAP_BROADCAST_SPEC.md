# 高德地图车机版对外标准广播协议全量参数规格书

## 一、广播注册与监听规范

* **标准广播 Action**：`AUTONAVI_STANDARD_BROADCAST_SEND`
* **发送组件**：高德地图车机版（`com.autonavi.amapauto`）
* **接收方式**：静态或动态广播接收器（`AmapBroadcastDecoder.kt`）

---

## 二、四大类核心参数全量规格字典

### 1. 基础行车与定位信息 (`KEY_TYPE = 10001`)
| Extra 键名 | 数据类型 | 示例取值 | 业务语义与说明 |
| :--- | :---: | :---: | :--- |
| `CUR_SPEED` | `Int` | `100` | 实时 GPS 车速 (km/h)。 |
| `LIMITED_SPEED` | `Int` | `120` | 当前道路法定限速 (km/h)，0 代表无限制。 |
| `CUR_ROAD_NAME` | `String` | `"京沪高速"` | 当前自车所在道路名称。 |
| `NEXT_ROAD_NAME` | `String` | `"五环路"` | 下一个转弯后的进入道路名称。 |
| `ROUND_ABOUT_NUM` | `Int` | `2` | 环岛出口序号 (经过第几个出口驶出)。 |

### 2. 导航路径引导与路口转向 (`KEY_TYPE = 10001`)
| Extra 键名 | 数据类型 | 示例取值 | 业务语义与说明 |
| :--- | :---: | :---: | :--- |
| `ICON` | `Int` | `2` | 导航转向图标代号 (1:直行, 2:左转, 3:右转, 4:左前方, 5:右前方, 8:调头, 9:靠左, 10:靠右, 11:进入环岛, 12:驶出环岛, 15:减速, 16:匝道)。 |
| `ROUTE_REMAIN_DIS`| `Int` | `12500` | 剩余全程总距离 (米)。 |
| `ROUTE_REMAIN_TIME`| `Int` | `650` | 剩余全程预计行驶时间 (秒)。 |
| `SEG_REMAIN_DIS` | `Int` | `350` | 距离下一个导航诱导动作点的剩余距离 (米)。 |

### 3. 电子眼与测速抓拍 (`KEY_TYPE = 10019`)
| Extra 键名 | 数据类型 | 示例取值 | 业务语义与说明 |
| :--- | :---: | :---: | :--- |
| `CAMERA_TYPE` | `Int` | `0` | 电子眼类型 (0:测速摄像头, 1:违章拍照, 2:应急车道拍照)。 |
| `CAMERA_SPEED` | `Int` | `100` | 测速摄像头限制时速 (km/h)。 |
| `CAMERA_DIST` | `Int` | `280` | 距离电子眼的剩余物理距离 (米)。 |

### 4. 车道拓扑与交通信号灯 (`KEY_TYPE = 10019` / `10020`)
| Extra 键名 | 数据类型 | 示例取值 | 业务语义与说明 |
| :--- | :---: | :---: | :--- |
| `EXTRA_DRIVE_WAY`| `String` | `"s/s/s/x/r"` | 车道拓扑字符流（`s`:直行通过, `x`:不可通行/盲道, `r`:右转, `b`:左转, `d`:公交专用）。 |
| `trafficLightStatus` | `Int` | `1` | 信号灯状态代号 (0:无, 1:红灯, 2:绿灯, 3:黄灯)。 |
| `redLightCountDownSeconds`| `Int` | `92` | 实时红灯动态倒计时秒数（直显于 HUD 仪表徽标）。 |
| `routeRemainTrafficLightNum`| `Int` | `5` | 剩余导航全流程中需经过的红绿灯总数。 |
