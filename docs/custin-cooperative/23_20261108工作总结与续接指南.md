## 2. 关键结论速查

### 2.1 高德车机版广播（实车抓包）

| KEY_TYPE | 何时发 | 关键字段 | 备注 |
|---|---|---|---|
| **10001** | **仅导航中** | `CAR_DIRECTION` 航向、`ICON` 转向、`SEG_REMAIN_DIS`、`LIMITED_SPEED`、`CUR_ROAD_NAME`、`CAMERA_DIST/TYPE`、`ROAD_TYPE` | 稀疏（数秒一条，有 4~5s 空档），且**交替发全零帧** |
| 12205 | 常态 | **仅 `EXTRA_GEOLOCATION=0`**（Integer，非定位对象） | ~1Hz |
| 10019 | 常态 | `EXTRA_STATE=40` | 偶发 |
| 13022 / 60021 | 偶发 | — | — |

**铁律**：
1. 纯地图态**没有航向**（想显示罗盘只能用车机 GPS）。
2. 收到 0 一律当"本次不更新"，不能覆盖上一帧。
3. 缺 `ICON` 时导航中要保留上一图标，否则会切罗盘。

### 2.2 百度 vs 高德 的仪表接入（Binder 实测）

```
1624(com.baidu.mapauto) -> 429(com.hsae.core)  call  size=104   ← 原生直连，70~100s 一次
高德(1876) -> com.hsae.core：0 次                                 ← 完全不直连
```

即：**百度原生对接仪表；高德靠 Reborn 转译**。
这是"百度能做到、高德做不到"的根本原因，不要试图从高德广播里找不存在的字段。

### 2.3 HSAE 仪表行为要点

- 罗盘通道 `displayType=8`：**每收到一帧就重绘外圈** → 不可保活重发。
- 箭头码位：65 直行 / 66 右前 / 67 右转 / 68 右后 / 69 左后 / 70 左转 / 71 左前 / 72 掉头。
- 本车实测**箭头左右与高德地图相反**，`mapTurnType` 已整体镜像。

## 8. 术语

- **TBT**：Turn-By-Turn，转向指引（箭头 + 距离）。
- **displayType**：HSAE 仪表图标码，`8` 专指罗盘，`255` 为未知/不显示。
- **navValid**：高德是否处于导航态（来自 `EXTRA_STATE`）。
- **罗盘模式**：`navValid=false` 且航向有效 → 发 `displayType=8`。
- **保活重发**：值不变也周期性重发，防止仪表超时清空；对罗盘**有害**（会重绘外圈）。
